# coop_exit_8
A very unfinished SM64 Coop DX adaptation of Exit 8. 

# Currently unimplemented anomaly ideas:
Everything is bouncy: you can bounce off of the trees, the signs, Yoshi... The butterflies.
Lakitu stops you: Lakitu from the 2nd half of the opening cutscene stops you on the bridge.
Castle door opens on its own: When you get close to it, it opens automatically. 
Stalker: There's a ghost (the same ghost_geo model I made for HyperCat's Toolbox because I'm a lazy fuck) that stalks you. woag. 
Bleeding Tree: One of the trees is bleeding. Wow. 

If you want to help implement them, I hope I've made it easy enough to do so.
